## A* 搜索算法

- 代码来源：博客园 https://www.cnblogs.com/helloylh/p/17209739.html
- 算法说明：本页代码使用的是A*启发式算法
- 注释说明：本页代码保留了作者原有的格式化风格， 原作者完全使用单行注释，我使用多行注释区分开来与原作者的注释
- 算法思路：
    1. 依次试探八个方向是否能走计算g代价
    2. 保留能走的点，存储在buff数组中
    3. 在buff数组中找到最小代价点（使用优先队列或者维护小根堆的效率更高，但是这作者纯小白），作为下一步拓展点，同时出队列（删除数组元素）
    4. 剩下还是bfs的那一套，直到判断终点（或者已经全部出队列表示死路一条）

## 加州房价回归分析

- 实现过程：大部分通过AI抽卡实现，还需要更多的时间学习和调试
- 文件结构：`linear_regression_manual.py`（模型实现）、`run_plain_regression.py`（普通回归）、`run_ridge_regression.py`（岭回归）
- 算法说明：手动实现多元线性回归，使用正规方程求解；引入L2正则化惩罚项实现岭回归
- 实现思路：
    1. 数据集的准备和划分为80%训练集和20%测试集
    2. Z-score标准化（转化为均值为0，标准差为1的分布），避免数据大的特征主导模型（让多个维度的权重有可比性）
    3. 模型训练：线性回归问题，试图照到一条拟合线，使得拟合预测值和实际值之间的误差最小
        - 加州房价：数据集共有8个特征，每个特征的属性对应一个权重，还有一个偏置项b，
          最后预测的房价 $y=\sum_{i=1}^8w_i x_i+b$，共有9个可学习的参数
        - L2正则化：为了防止模型过拟合（函数图线像过山车一样曲折地经过每一个点），
          我们希望尽可能降低权重大小，从而限制函数的扭曲，使得函数图线简单平滑。
          因此，把权重平方和纳入损失函数，使得模型向简单的拟合线收敛

损失函数为预测值和实际值之间的均方误差（MSE），加上L2正则化项：

$$ L = (Xw - y)^\top (Xw - y) + \lambda w^\top w $$

损失函数是一个关于 w 的凸函数，对 w 求导并令导数为零即为最小损失：

$$ (X^\top X + \lambda I) w = X^\top y $$

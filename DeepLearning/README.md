## 学习笔记

_论文题目：Batch Normalization:
Accelerating Deep Network Training by Reducing Internal Covariate Shift
(批量归一化：通过减少内部协变量偏移加速深度网络训练)_

### 协方差偏移导致了一些问题

1. 神经网络的训练过程中，上层的参数随着训练改变， 使得下层的输入值的的分布改变，
2. 微小参数的改变会随着层数加深对下层输入值分布产生显著影响，
3. 下层需要继续学习改变参数来适应新的分布，导致训练速度变慢

### 白化解决思路

- 为了解决分布改变问题，出现了白化（whitening）的方法
- 白化会把输入值变为标准正态分布，避免了输入值的分布改变，（理论上）加速收敛速度

### 白化引入了新的问题

为了更快的下降和避免多通道重复表达的冗余，引入了去相关的概念，而去相关导致巨大的性能开销

### BN绕开白化的性能问题

1. 批归一化放弃了“去相关”的步骤，但保留了标准化稳定输入值的策略
2. 批归一化只需要对每一批的数据进行处理，而不是整个数据集

### BN为提高表达能力提供了补充两个参数：平移因子β、缩放因子γ

1. 补充的两个参数可以学习，使得模型可以更自由，可以学习到更合适的分布
2. 缩放因子可以增大对比度来提高对关键信息的敏感度，也可以减小来抑制噪声通道的捕捉
3. 平移因子一方面可以弥补标准化无脑中心化导致输入分布的不合理的偏移，缓解缩放因子独自承担调整分布的压力；
   另一方面可以避免归一化直接跟着ReLU函数导致一半的数据直接留在死区，丢失信息
4. 平移+缩放的组合在激活函数的搭配下（比如SiLU、ReLU、Sigmoid，这些函数有斜率的变化），
   相当于调整了激活函数的输出结果的转折点，提高了非线性的能力
   （以sigmoid为例子，不至于让大跨度的数据分布留在梯度消失，也不会挤在0附近导致函数近似退化成线性）

### 额外的好处

1. 同样的样本，不同的mini-batch中会被不同均值方差所归一化，导致每一批的结果都带有随机的扰动，起到正则化的作用，抑制过拟合
2. 由于输入数据分布变化稳定了，就可以使用更大的学习率，加速收敛
3. 卷积层后使用BN层的平移因子β可以取代卷积层中的偏置项b
   （也不能完全算好处吧，如果不是归一化操作会抹去卷积偏置的作用，β只是在做和b一样的操作）
4. 自适应学习率的作用：权重尺度较大时，特征方差也会变大，反向传播的梯度随归一化操作而减小，学习率较稳定；
   权重尺度较小时，特征方差也会变小，反向传播的梯度会因归一化操作增大，避免了小权重训练停滞
